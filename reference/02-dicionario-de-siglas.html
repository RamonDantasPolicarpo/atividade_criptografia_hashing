Documento de Referência 02

Dicionário Descomplicado de Siglas

Guia definitivo para dominar todos os termos e siglas que aparecem no seminário e no backend.

KDF Hashing
Key Derivation Function (Função de Derivação de Chave)

Um algoritmo projetado para transformar uma senha em uma chave ou hash através de milhares de iterações matemáticas lentas.

No Backend: É o que bcrypt, Argon2 e PBKDF2 são. Serve para impedir que computadores rápidos adivinhem senhas.
SHA Hashing
Secure Hash Algorithm (Algoritmo de Hash Seguro)

Família de funções de hash (SHA-1, SHA-256, SHA-512, SHA-3) criada pelo NIST. É rápida e focada em integridade de arquivos e assinaturas digitais.

No Backend: Excelente para verificar se um download não foi corrompido; nunca para guardar senhas.
Argon2id Hashing
Argon2 Hybrid (Versão Híbrida do Argon2)

O algoritmo mais moderno e seguro da atualidade para senhas. É memory-hard (consome muita memória RAM) para travar placas de vídeo de atacantes.

No Backend: O padrão ouro recomendado pela OWASP para novos projetos hoje.
ASIC / GPU Hardware / Ataque
Application-Specific Integrated Circuit / Graphics Processing Unit

Hardware especializado com milhares de núcleos de processamento paralelos, frequentemente usado por cibercriminosos para tentar bilhões de senhas por segundo.

No Backend: A razão pela qual criamos o Argon2 (que exige muita RAM, onde a GPU é fraca).
HMAC Hashing / Autenticação
Hash-based Message Authentication Code

Um hash gerado em conjunto com uma chave secreta. Garante não só que a mensagem não mudou, mas que foi enviada por quem tem a chave.

No Backend: A base que assina os tokens JWT que usamos em APIs REST.
TLS Trânsito
Transport Layer Security (Segurança da Camada de Transporte)

O sucessor moderno do antigo SSL. É o protocolo criptográfico que transforma o HTTP inseguro no HTTPS seguro com cadeado verde.

No Backend: Protege o tráfego contra invasores espionando Wi-Fi ou provedor (ataques Man-in-the-Middle).
mTLS Trânsito
Mutual Transport Layer Security (TLS Mútuo)

Enquanto o TLS normal só o servidor prova quem é, no mTLS o cliente também apresenta um certificado digital criptográfico para o servidor.

No Backend: Muito usado para comunicação interna ultra segura entre microsserviços.
CA Trânsito
Certificate Authority (Autoridade Certificadora)

O "cartório" digital da internet (ex: Let's Encrypt, DigiCert) que emite e atesta que o certificado TLS pertence de fato ao seu domínio.

No Backend: Sem uma CA confiável, os navegadores exibem tela vermelha de "Sua conexão não é particular".
MitM Ataque
Man-in-the-Middle (Homem no Meio)

Ataque em que um interceptador espiona ou altera mensagens transmitidas entre duas partes que acreditavam estar falando diretamente.

No Backend: Totalmente neutralizado pelo uso correto de TLS 1.3 e certificados válidos.
AES-GCM Repouso
Advanced Encryption Standard - Galois/Counter Mode

O padrão mundial de cifra simétrica de dados. O modo GCM fornece criptografia com autenticação (AEAD), impedindo que dados cifrados sejam alterados sem detecção.

No Backend: A cifra ideal para criptografar campos sensíveis no banco (CPF, cartão, prontuário).
KMS Repouso / Gestão
Key Management Service (Serviço de Gestão de Chaves)

Serviço de nuvem ou cofre de segurança (AWS KMS, Google Cloud KMS, Vault) que guarda e gerencia as chaves mestras de criptografia em hardware blindado (HSM).

No Backend: Impede o erro de desenvolvedor iniciante de commitar a chave de criptografia no GitHub ou no `.env`.
IV / Nonce Repouso
Initialization Vector / Number used once

Um número aleatório de uso único gerado a cada nova criptografia AES. Garante que criptografar o mesmo dado duas vezes gere resultados visivelmente diferentes.

No Backend: Sem IV único, um invasor consegue descobrir padrões estatísticos nos dados salvos.
