# Criptografia Aplicada & Proteção de Dados - Resources

## Knowledge

- [Vídeo: YuriRDev - Criptografia na Prática](https://www.youtube.com/@YuriRDev)
  Excelente introdução visual e prática em português para desenvolvedores backend sobre segurança, senhas e criptografia. Use para: introduzir a intuição prática e exemplos reais do ecossistema.
- [OWASP: Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
  Guia oficial e padrão da indústria para armazenamento seguro de senhas. Use para: parâmetros recomendados de bcrypt, Argon2id e scrypt.
- [OWASP: Cryptographic Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)
  Padrão de referência para proteção de dados em repouso. Use para: seleção de cifras autenticadas (AES-GCM), gerenciamento e rotação de chaves.
- [OWASP: Transport Layer Protection Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Transport_Layer_Protection_Cheat_Sheet.html)
  Diretrizes para comunicação segura em trânsito. Use para: configurações recomendadas de TLS, HSTS e certificados.
- [RFC 9106: Argon2 Memory-Hard Function for Password Hashing and Proof-of-Work Applications](https://datatracker.ietf.org/doc/html/rfc9106)
  Especificação formal do algoritmo Argon2 (Argon2d, Argon2i, Argon2id). Use para: parâmetros de custo de memória, iterações e paralelismo.
- [RFC 8446: The Transport Layer Security (TLS) Protocol Version 1.3](https://datatracker.ietf.org/doc/html/rfc8446)
  Especificação do TLS 1.3. Use para: entender a redução de round-trips no handshake e a remoção de cifras legadas inseguras.

## Wisdom (Communities)

- [OWASP Community (Slack / Chapters Brasil)](https://owasp.org/)
  Comunidade global de especialistas em segurança de aplicações. Use para: tirar dúvidas sobre conformidade e melhores práticas de mercado.
- [r/crypto](https://reddit.com/r/crypto)
  Subreddit de discussão técnica sobre teoria e implementação de algoritmos criptográficos. Use para: discussões aprofundadas sobre propriedades matemáticas e notícias de vulnerabilidades.
- [r/netsec](https://reddit.com/r/netsec)
  Comunidade de segurança da informação e engenharia de redes. Use para: estudos de caso de vazamentos de dados e ataques reais a tráfego TLS/bancos de dados.
